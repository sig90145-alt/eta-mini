# 로컬 서버에 접속하는 주소 (`127.0.0.1:8080`)

> 작성: 2026-11-13 16:52

서버를 아래 명령으로 띄웠습니다.

```powershell
uv run uvicorn api.app:app --port 8080 --reload
```

그런데 브라우저에서 `http://0.0.0.127/` 로 들어가니 아무것도 뜨지 않았습니다.
주소에서 **두 군데**가 틀렸기 때문입니다.

| | 입력한 주소 | 올바른 주소 |
| --- | --- | --- |
| IP | `0.0.0.127` (숫자 순서가 거꾸로) | `127.0.0.1` |
| 포트 | 없음 → 80번으로 접속됨 | `:8080` |

👉 올바른 주소: **http://127.0.0.1:8080/** 또는 **http://localhost:8080/**

---

## 1. 주소는 "건물 주소 + 호수"

웹 주소 `http://127.0.0.1:8080/health`는 네 부분으로 나뉩니다.

```
http://  127.0.0.1  :8080  /health
  │          │        │       │
  │          │        │       └─ 경로: 서버 안에서 어떤 기능을 쓸지
  │          │        └─ 포트: 그 컴퓨터에서 어떤 프로그램에게 갈지
  │          └─ IP 주소: 어떤 컴퓨터로 갈지
  └─ 프로토콜: 어떤 방식으로 통신할지
```

> 비유: **IP 주소는 아파트 건물 주소**, **포트는 호수**입니다.
> 건물 주소가 틀리면 엉뚱한 건물로 가고,
> 건물이 맞아도 호수가 틀리면 아무도 없는 집 문을 두드리게 됩니다.

---

## 2. `127.0.0.1`: "내 컴퓨터 자신"

- `127.0.0.1`은 **지금 이 컴퓨터 자기 자신**을 가리키는 특별한 IP 주소입니다.
- 이런 주소를 **루프백(loopback) 주소**라고 부릅니다. 요청이 밖으로 나가지 않고 내 컴퓨터로 되돌아옵니다.
- **`localhost`는 `127.0.0.1`의 이름**입니다. 둘 중 무엇을 써도 됩니다.

`0.0.0.127`은 숫자만 같고 순서가 거꾸로인 **전혀 다른 주소**입니다.
IP 주소는 점(`.`)으로 나뉜 네 숫자의 **순서까지 맞아야** 합니다.

### 헷갈리기 쉬운 주소들

| 주소 | 뜻 | 브라우저에 입력? |
| --- | --- | --- |
| `127.0.0.1` / `localhost` | 내 컴퓨터 자신 | ✅ 이걸 씀 |
| `0.0.0.0` | 서버 설정에서 "모든 네트워크에서 요청을 받겠다"는 뜻 | ❌ 접속용 아님 |
| `0.0.0.127` | 오타 (의미 없는 주소) | ❌ |

> 참고: 나중에 `--host 0.0.0.0` 같은 옵션을 보게 됩니다.
> 이것은 서버에게 어디서 오는 요청을 받을지 알려주는 설정입니다.
> 브라우저에 입력하는 주소가 아닙니다.

---

## 3. 포트: 한 컴퓨터 안의 "문 번호"

컴퓨터 한 대에서 여러 프로그램이 동시에 네트워크를 쓸 수 있습니다.
그래서 각 프로그램은 **자기 포트 번호**를 하나씩 맡아서 그 번호로 오는 요청만 받습니다.

이번에는 서버를 `--port 8080`으로 띄웠습니다. 그러니 주소에도 `:8080`을 붙여야 합니다.

### 포트를 안 쓰면?

브라우저는 포트를 생략하면 **기본 포트**로 접속합니다.

| 프로토콜 | 기본 포트 |
| --- | --- |
| `http://` | 80 |
| `https://` | 443 |

`http://127.0.0.1/` 은 사실 `http://127.0.0.1:80/` 과 같습니다.
80번 포트에는 실행 중인 서버가 없으니 접속에 실패합니다.

---

## 4. 이 프로젝트에서 쓸 수 있는 주소

서버가 떠 있을 때 아래 주소로 접속할 수 있습니다.

| 주소 | 보이는 것 |
| --- | --- |
| http://localhost:8080/ | API 소개 페이지 |
| http://localhost:8080/health | 서버 상태 `{"status":"ok","model":"rule"}` |
| http://localhost:8080/docs | FastAPI가 자동으로 만든 API 문서 (여기서 `/eta`를 직접 호출해 볼 수 있음) |

`/eta`는 POST 요청이라 브라우저 주소창으로는 호출할 수 없습니다.
`/docs` 페이지를 쓰거나 PowerShell에서 아래처럼 호출합니다.
자세한 내용은 [PowerShell-bash-차이.md](PowerShell-bash-차이.md)를 보세요.

```powershell
Invoke-RestMethod -Method Post -Uri http://localhost:8080/eta -ContentType "application/json" -Body '{"distance_km": 3, "pending_orders": 2}'
```

## 5. 접속이 안 될 때 확인 순서

1. **서버가 떠 있나?** 서버 터미널에 `Uvicorn running on http://127.0.0.1:8080`이 보여야 합니다.
2. **IP가 맞나?** `127.0.0.1` 또는 `localhost`로 입력했는지 확인합니다.
3. **포트가 맞나?** 서버를 띄울 때 쓴 `--port` 번호와 주소의 `:번호`가 같은지 확인합니다.
4. **`http`인가?** 로컬 서버는 보통 `https`를 쓰지 않습니다. `https://localhost:8080`으로는 접속되지 않습니다.
5. **서버 터미널에 로그가 찍히나?** 요청이 서버에 닿으면 아래 같은 줄이 생깁니다.
   이 로그가 안 찍히면 요청이 서버까지 가지 못한 것이니 1~4를 다시 확인합니다.
   ```
   INFO:     127.0.0.1:xxxxx - "GET / HTTP/1.1" 200 OK
   ```
